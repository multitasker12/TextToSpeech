# 🎙️ AI Voice Studio - Text to Speech Converter

यह एक professional Text to Speech website है जो users को text को natural voice में convert करने की सुविधा देती है।

## ✨ Features

- 🎙️ **10 Professional Hindi Voices** (5 Male + 5 Female)
- 🌐 **Browser-based TTS** - No API required
- 📱 **Fully Responsive** - Mobile & Desktop friendly
- 🎨 **3D Animated Interface** - Beautiful particle effects
- ⚡ **Instant Generation** - Real-time speech synthesis
- 💾 **Download Support** - Save generated audio
- 🔍 **SEO Optimized** - Google search friendly

## 🚀 Live Deployment

### GitHub Pages (Recommended)
1. Repository create करें: `ai-voice-studio`
2. सभी files upload करें
3. Settings → Pages → Source: Deploy from branch
4. Main branch select करें
5. Save करें
6. Website live हो जाएगी: `https://username.github.io/ai-voice-studio`
